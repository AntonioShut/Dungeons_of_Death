# Dungeons_of_Death
Здесь представлено описание проекта Dungeons of Death. Это компьютерная игра в жанре средневекового фентези и пошаговой стратегии, где вы выбираете себе героя и играя за него зачищаете древнее подземелье которое прозвали "Подземелье Смерти".
Игра двумерная в 16 битном стиле. На начало игры будут представлены три класса Теневой Маг, Вор и Воин.

#КАК СКАЧАТЬ?
Скачать нашу игру очень просто, в данный момент игра находится в гугл диске и вы должны перейти по этой ссылке:

https://drive.google.com/drive/folders/1htza0FSNlQsTfkuJkBqakOlvfn0lCGlz?usp=sharing   - ссылка на наш проект

После перехода вы увидете перед собой zip архив, скачивайте его на своё устройство. Когда архив скачается, вы должны создать у себя на устройстве папку Dungeons_of_Death, и извлеч содержимое скачанного архива в эту папку. Для запуска игры, нужно запустить game.exe.
